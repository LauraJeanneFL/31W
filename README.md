31W - Introduction à un gestionnaire de contenu
TP1: Conception d'un plugin Wordpress

 Date de remise    Semaine 6            

Objectifs du TP1:
1.	Développer une extension WordPress (« plugin ») pour un site web de club de voyage. Ce club propose à ses membres des voyages vers des destinations uniques à travers le monde. Chaque destination sera classée par catégorie pour que les membres puissent s'informer en fonction de leurs préférences.
2.	Le plugin permettra de gérer un carrousel d’images caractérisant les destinations de voyage.
3.	Déployer le projet sur le serveur Web Hosting Canada (WHC).
Le plugin à développer:  Carrousel d’images
•	Le carrousel permet d’afficher les images d’une galerie. 
•	Les fonctionnalitiés de Navigation :
o	Une série de boutons radio permettant d’accéder à chacune des images
o	Deux flèches « Précédent » et « Suivant »
o	En cliquant sur une image de la galerie le carrousel s’affiche avec l’image sélectionné
o	Le changement d’image est animé
o	La dimension de la boîte modale s’adapte aux proportions de l’image source et à la fenêtre du navigateur.
Déroulement du projet
Les « commits » seront poussés dans le dépôt 31W de votre GitHub dans la branche tp1.
L'ensemble des commits devra s'étaler progressivement à partir de la journée de remise du devis jusqu'à la remise finale du TP.
Un minimum de 20 commits pour le plugin permettra d'évaluer l'évolution de votre projet.
Le serveur « WHC » Web hosting canada
Utilisez votre compte «WHC » pour déployer la version finale de votre site.
Gardez votre environnement de fichiers « WHC » le plus simple possible en retirant tous les éléments non nécessaires.
 
Barème de correction sur 25 points
1.	Organisation des commits sur GitHub minimum 20 commits pour le thème (5 points)
•	Minimum de 20 commits étalés sur toute la durée du TP
•	Messages clairs, spécifiques, préfixés et non redondants
•	Une branche tp1
•	Déploiement de votre site sur « WHC »
•	Un readme.md pour le thème: auteur, titre du projet, description et lien vers votre site sur l’hébergeur « WHC »

2.	Organisation de la codification du plugin (10 points)
•	Structure de dossiers/fichiers : Sass, Javascript, style.css, carrousel.php (1 point)
•	Programmation : Modularité du code, efficacité, standard de nommage des identificateurs, commentaires (9 points)
o	Javascript, PHP, Sass

3.	Fonctionnement du carrousel (10 points)
•	Affiche l’ensemble des images d’une galerie (1 point)
•	S’intègre facilement au contenu d’un thème WP (1 point)
•	La navigation est entièrement fonctionnelle (flèche, bouton radio) (2 point)
•	Le lancement du carrousel est réalisé en sélectionnant une image de la galerie. (2 point)
•	Le changement d’image est animé (2 point)
•	Le carrousel s’affiche dans une boîte modale adaptative. (2 point)
